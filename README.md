# My First Project - עמוד פורטפוליו

עמוד פורטפוליו אישי סטטי, בנוי ב-HTML, CSS ו-JavaScript טהורים (ללא ספריות חיצוניות).

## תכונות

- עיצוב רספונסיבי (מובייל / טאבלט / דסקטופ)
- מצב כהה / בהיר עם שמירת העדפה ב-localStorage
- ניווט חלק בין קטעים
- טופס יצירת קשר (צד לקוח בלבד, ללא שרת)
- קטעי עליי, פרויקטים וכישורים

## מבנה הפרויקט

```
.
├── index.html
├── css/
│   └── style.css
├── js/
│   └── main.js
└── assets/
```

## הרצה מקומית

פשוט פתחו את `index.html` בדפדפן, או הריצו שרת סטטי:

```bash
python3 -m http.server 8000
```

ואז גשו ל-`http://localhost:8000`.
